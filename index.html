07 FOMO Games

Built around a clock, not a menu.

Short windows and visible countdowns — the format that gets someone to act now instead of later.

Flash-drop challenge

A single question or task unlocks for a fixed window; first correct answers claim a spot on the board.

02:14

Limited-seat rush

Booking slots that visibly run out, reusing the same engine behind the quiz system.

Streak keeper

Miss one round's window and the streak resets — built to reward showing up on time.

Notify-to-play

WhatsApp / SMS ping fires minutes before a round opens, so nobody's watching a static screen.

Coin-drop events

In-game currency drops timed to match real event moments, carried over from the reward system built for Mjomaker.

08 Event-Specific Builds

Made for one event, shaped like a product.

One-off games and screens built around a specific event's schedule, branding, and audience — every event gets its own version, not a shared template.

Pre-event

Registration + reminder flow

Signup is verified on the spot, slots are held against a fixed capacity, and reminders go out before each round or slot so nobody misses their window.

Day-of

Check-in, no queue

Attendees confirm their spot from their own phone as they arrive — the room fills without a line forming at a single check-in desk.

During

Two views, one game

A big screen for the whole room — showing polls, leaderboards, and drops — paired with a lightweight phone view participants join by QR code, no app required.

Live support

Someone's watching the whole time

The dashboard stays open through the event — a stuck slot, a missed notification, or a late arrival gets fixed in the moment, not after.

Wrap-up

Scoreboard + follow-up ping

Final results post to the shared screen immediately, and a follow-up message with the results goes out the same way the reminders did.

09 Data & Control

Every event, one dashboard.
